# Customer Behavior Dashboard 🛍️

An interactive **Power BI** dashboard analyzing customer purchase behavior — subscription status, spending by category and age group, and shipping preferences — to help identify which customer segments drive the most value.

![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat&logo=powerbi&logoColor=black)
![DAX](https://img.shields.io/badge/DAX-0078D4?style=flat)

---

## 📌 Overview

This single-page interactive dashboard explores a customer purchase dataset to answer key behavioral questions: which categories customers spend the most on, how spending varies by age group, how subscription status splits across the customer base, and how customers filter by gender and shipping preference.

---

## 🛠️ Tools & Techniques

- **DAX Measures** — built custom measures for key KPIs: `Number of Customers`, `Average Purchase Amount`, and `Average Review Rating`
- **Interactive Filtering** — 4 slicers (Subscription Status, Gender, Category, Shipping Type) let users drill into any customer segment
- **Multiple Chart Types** — donut chart (subscription status split), column charts (spend by category, customer count by category), and clustered bar charts (spend by age group, customer count by age group)

---

## 📊 Dashboard Contents

| Visual | What it shows |
|---|---|
| KPI Cards | Total number of customers, average purchase amount, average review rating |
| Donut Chart | Customer split by subscription status |
| Column Chart | Total purchase amount by product category |
| Column Chart | Customer count by product category |
| Clustered Bar Chart | Purchase amount by age group |
| Clustered Bar Chart | Customer count by age group |
| Slicers | Subscription Status · Gender · Category · Shipping Type |
